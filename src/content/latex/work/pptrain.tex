\section{Overview}

Prepretraining initializes a language model on synthetic or abstract sequences before continuing training on natural text. \href{https://github.com/Axym-Labs/pptrain}{\texttt{pptrain}} exposes paper-derived task generators through common interfaces for upstream training, weight transfer, and evaluation. It installs with

\begin{verbatim}
pip install pptrain
\end{verbatim}

The built-in families generate neural cellular automata rollouts (\texttt{nca}), balanced-bracket sequences (\texttt{dyck}), short programs (\texttt{procedural}), copy, set, and query transformations (\texttt{simpler\_tasks}), induction, deduction, and abduction problems (\texttt{lime}), and synthetic document transformations (\texttt{summarization}). Paper-derived presets expose configurable generation and dataset fields.

\section{Example: prepretrain a Hugging Face model}

The first example prepretrains a small GPT-2 on neural cellular automata rollouts and transfers the weights into a fresh downstream model. The embedding layer is reinitialized because the synthetic vocabulary differs from the natural-text one.

\begin{verbatim}
from pptrain import PrePreTrainer, RunConfig, create_task
from pptrain.integrations import HFCausalLMAdapter, HFModelConfig
from pptrain.transfer import ReinitializeEmbeddingTransferPolicy

trainer = PrePreTrainer(
    task=create_task("nca", {"preset": "smoke"}),
    model_adapter=HFCausalLMAdapter(
        HFModelConfig(model_name_or_path="sshleifer/tiny-gpt2")
    ),
    run_config=RunConfig(output_dir="runs/nca", max_steps=20),
)
bundle = trainer.fit().load_transfer_bundle()

target_model = trainer.model_adapter.load_downstream_model()
policy = ReinitializeEmbeddingTransferPolicy()
report = policy.apply_bundle(bundle, target_model)
print(report.loaded_parameter_count)
\end{verbatim}

\section{Example: bring your own architecture}

The second example builds the upstream model from the synthetic vocabulary size, prepretrains it on balanced-bracket sequences, and copies every parameter except the token embedding and output head into the downstream model.

\begin{verbatim}
from transformers import GPT2Config, GPT2LMHeadModel
from pptrain import PrePreTrainer, RunConfig, create_task
from pptrain.integrations import VocabSizeCausalLMAdapter
from pptrain.transfer import SkipParametersTransferPolicy


def gpt2(vocab_size: int) -> GPT2LMHeadModel:
    return GPT2LMHeadModel(GPT2Config(
        n_layer=2, n_head=2, n_embd=64,
        n_positions=128, vocab_size=vocab_size,
    ))


trainer = PrePreTrainer(
    task=create_task("dyck", {"preset": "smoke"}),
    model_adapter=VocabSizeCausalLMAdapter(
        create_prepretrain_model=gpt2,
        load_downstream_model=lambda: gpt2(vocab_size=50257),
    ),
    run_config=RunConfig(output_dir="runs/dyck", max_steps=20),
)
bundle = trainer.fit().load_transfer_bundle()

target_model = gpt2(vocab_size=50257)
policy = SkipParametersTransferPolicy(
    skip_parameter_prefixes=("transformer.wte", "lm_head"),
)
report = policy.apply_bundle(bundle, target_model)
print(report.loaded_parameter_count)
\end{verbatim}

\section{Verify and evaluate}

Reference-parity tests compare normalized examples or token sequences with fixtures produced by the original LIME, synthetic-summarization, procedural-pretraining, and NCA implementations. The replication interface compares downstream training after synthetic initialization with both random initialization and a natural-text warmup, then exports the resulting metrics, plots, tables, and reports.

A custom symbolic generator implements \texttt{SymbolicTaskFamily} by defining how an example is sampled, executed, serialized, and tokenized. A method that requires a different dataset construction or loss implements \texttt{Task} directly.
